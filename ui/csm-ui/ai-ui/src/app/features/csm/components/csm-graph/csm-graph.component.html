Why Web Workers?

In standard web applications, JavaScript runs on a single thread. Complex computations (like calculating projections across 10,000+ policies) would freeze the UI and create lag.

By using an HTML5 Web Worker, we offload this heavy calculation to a background CPU thread. The chart stays interactive, CSS animations stay smooth, and the worker simply passes the completed array structures to the main thread every 2 minutes.
